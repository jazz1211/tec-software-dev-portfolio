Laboratorio 5  - Git: 
En este laboratorio se aplicaron conocimientos básicos y prácticos sobre control de versiones con  Git y GitHub. Se realizaron acciones como la creación de repositorio, registro de cambios, sincronización con GitHub y manejo de flujos de trabajo.

Pasos:
•	Paso 1: Se creó el repositorio “tec-software-dev-portfolio” en GitHub y la carpeta local “laboratorio-git”.
•	Paso 2: Se inicializó Git en el proyecto, se creó el archivo “README.md” y se realizó el primer commit.
•	Paso 3: Se enlazó el repositorio local con GitHub y se subió el proyecto a /main.
•	Paso 4: Se verificó el remoto, la conexión SSH, el estado del repositorio.
•	Se creó la carpeta “laboratorios” y se subieron los laboratorios realizados en el curso.

Reflexión:
Este laboratorio fue de mucha utilidad para entender el funcionamiento de herramientas como Git / Github en el control de versiones. La práctica me permitió ver la importancia de mantener un repositorio organizado, registrar los cambios, y conservar un historial de actualizaciones de los proyectos. Fue de mucho provecho para entender y aprender la gestión eficiente del código.

Conclusión general: 
Se aprendió a usar Git y GitHub para controlar versiones, organizar archivos y registrar cambios. Estos conocimientos son útiles porque facilitan el trabajo ordenado y colaborativo en proyectos software.
